# 全局动物插画规范

固定基础 Prompt：

“clumsy, scribbly, and utterly pathetic way possible. Use same color, and make it look like it was drawn in MS Paint with a mouse. It should be vaguely similar but also not really, kind of matching but also off in a confusing, awkward way, with that low-quality pixel-by-pixel feel that really emphasizes how ridiculously bad it is.”

画布 1024×1024、1:1，主体占高度65%至78%，四周留白至少12%。最终导出透明 PNG，文件名为 `public/animals/{event-slug}.png`。三分之四视角、全身优先；锯齿状鼠标手绘轮廓，统一6至9像素视觉粗细；填色不均匀，不做真实毛发。限定色板：#2b2925、#6b655d、#9b8c78、#b8a995、#d8c8ad、#9eb2a1、#985946、#f0e8dc。无落地投影。

统一限制：transparent background; no text; no typography; no watermark; no decorative frame; no gore; no visible wounds; no blood; full body or clearly readable half body; roughly three-quarter view; jagged mouse-drawn outline; visibly uneven fill areas; awkward anatomy; low-resolution MS Paint feeling; same limited palette; same outline thickness; same canvas ratio; same visual scale; intentionally amateur, but still identifiable as the correct species.
